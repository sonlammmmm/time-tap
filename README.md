# time-tap

Poker Shot Clock — Full-Screen Action Countdown Timer with customizable warning times and custom voice recording.

## Features
- **Accurate Poker Shot Clock**: Clean dark mode, huge digits, progress bar, 1-tap reset dealer mechanics.
- **Custom Time & Warning Thresholds**: 15s, 20s, 30s, 45s, 60s or custom seconds. Amber warning and Red critical thresholds.
- **Custom Voice Recording**: Record your own warning and time-up audio alerts using your iPhone microphone.
- **iOS IPA Sideload**: Automated GitHub Actions workflow to build native iOS IPA for SideStore, AltStore, and TrollStore.
- **PWA Ready**: Add to Home Screen in Safari for full-screen native experience.
